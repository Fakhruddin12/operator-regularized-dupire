# Dupire literature benchmark inputs

Retrieved and inspected on 22 October 2026. This input bundle was assembled before calibration; current controlled comparison results are stored separately under outputs/stage_23_literature_audit_final/ and reports/literature_audit/ in the audited project.

## Included inputs

1. eurostoxx_2010_155_quotes.json: 155 nonmissing implied-volatility quotes at 12 maturities from the Andreasen-Huge example in QuantLib, dated 1 March 2010. Geng, Navon and Chen (2014) reuse this benchmark. The JSON retains source maturity labels and the actual/365 maturities produced by QuantLib's integer-day conversion. Use one convention consistently for all competitors. The source's zero entries indicate missing observations, not zero volatility. There are no historical bid-ask spreads. Rate and dividend inputs are both zero under the benchmark convention. This is a public transcription, not a verified byte-for-byte copy of Geng's original input file.

2. ackerer_original_bates_train_data.csv: the unchanged 324-row synthetic dataset inside the official NeurIPS 2020 supplement of Ackerer, Tagasovska and Vatter. Fields include maturity, log-moneyness, put/call value, implied volatility and total variance. Missing values are intentional; inspect option type and normalization before using price fields. The supplement also offers R/TensorFlow model code, downloadable from the source link below. Synthetic quote_date values do not represent historical observations. This is a price-surface benchmark generated by a Bates model with jumps, not an observed ground-truth local-volatility surface.

3. provenance.json: download links and SHA-256 fingerprints.

## Other availability findings

Albani et al. (2017), arXiv:1512.07660, Section 5.1 specifies a synthetic local-volatility surface, generation mesh, 1% multiplicative normal quote noise and observation grid. Its experiment can be regenerated, but the original noise realization was not retrieved. Their real examples include SPX on 19 June 2015 and WTI/Henry Hub on 6 September 2013. No public raw quote download was located in the inspected paper, publisher page or author publication page; that is not proof that none exists.

The older October 1995 S&P 500 source table is available in Coleman, Li and Verma, Table 2. It has 100 entries overall and 70 with maturity at most two years, whereas Geng reports 57 observations. Do not describe an arbitrary subset of this table as Geng's exact 57-quote input. The subset must be reconciled first.

Ackerer's actual historical SPX dataset uses OptionMetrics/WRDS; the authors explicitly state that it cannot be publicly shared. It is absent from their downloaded supplement.

## Fair comparison design

Separate a reproduction of published procedures from a controlled test of the penalty. For the latter, hold log-variance coordinates, reference surface, pricing solver, correction grid, taper and weighting fixed; vary only the penalty. Tune each method on training/validation observations. Refit SSVI and compute quote support using training observations only. A maturity holdout must exclude those observations from prior fitting and tuning as well as correction fitting. Do not compare newly defined test errors directly with a paper's in-sample residual.

For synthetic surface recovery, use an independently refined generation solver and repeat noise draws. Evaluate recovery error only where ground truth is known. For market/Bates inputs, emphasize withheld price/IV error, stability, no-arbitrage checks and runtime; they do not supply local-volatility ground truth. Include reference-misspecified scenarios with real deviations in sparse regions.
